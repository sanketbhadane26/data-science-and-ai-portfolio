A simple calculator program built with Python as part of my Python learning roadmap.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Division-by-zero error handling
- Invalid operator handling

## Concepts Practiced

- Variables
- User input
- Data types
- Operators
- if / elif / else
- Nested conditions
- f-strings
- Basic error handling

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder.
4. Run

```bash
